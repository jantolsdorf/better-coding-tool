Qualitative coding, in your browser

  1. Add interview transcripts as .txt files (or drop them on the document list).
  2. Open a document and highlight a passage.
  3. Type a code and press Enter. Existing codes are suggested as you type.
  4. Export your project to share it; import others’ exports to compare coding side by side.

Everything is stored in this browser’s local storage. Export regularly to keep a backup.
